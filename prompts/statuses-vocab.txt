# 状态库词表（Statuses Vocab）v1.9.0
#
# 用途：把主模型写的「状态 key」具象化成**可直接进提示词**的详情（detail），并存档复用。
# 为什么需要：晒黑/吻痕/淤青/染发这些**有时效**的东西写在【要点】里，每轮都可能换一种说法 →
#             同一道痕迹换个词就变了样。具象化一次存档，之后原样复用。
#
# ══ 三条核心原则（和造型库完全一致）══
#   1. 【只存"是什么"，不存"现在怎么样"】
#        ✅ 左颈，暗红色，椭圆形，吻痕
#        ❌ 吻痕淡了些 / 晒得更黑了 / 淤青快消了      ← 这些属于【要点】，进去会被永久冻死
#   2. 【原子化】拆成独立可命中的原子
#        ✅ 左颈，暗红色，椭圆形，吻痕      ❌ 脖子上有个很明显的吻痕
#   3. 【key 由主模型写，插件原样使用】
#
# ══ 维度表（按需取，不必全写）══
#
# 【痕迹类】
#   类型  吻痕 / 抓痕 / 咬痕 / 勒痕 / 鞭痕 / 淤青 / 擦伤 / 划伤 / 烧伤 / 针眼
#   位置  左颈 / 右颈 / 锁骨下 / 右肩 / 胸口 / 乳侧 / 腰侧 / 大腿内侧 / 手腕 / 脚踝 / 后背
#   颜色  暗红 / 紫红 / 青紫 / 浅褐 / 红肿 / 发白
#   形态  椭圆形 / 圆形 / 条状 / 指印状 / 点状 / 片状 / 网状
#   状态（**不进 detail**）：新鲜 / 转淡 / 结痂 / 快消退
#
# 【肤色 / 肤质变化】
#   晒黑（小麦色 / 蜜色 / 晒痕分布）· 晒伤（发红 / 脱皮）· 苍白 · 潮红 · 泛红
#   湿身 · 汗湿 · 油光 · 沾水 · 沾泥 · 沾血 · 沾奶
#
# 【毛发变化（半永久）】
#   染发（金色 / 奶茶棕 / 挑染 / 发根长出原色）· 剪短 · 剃光 · 剃毛（腋下 / 腿部 / 私处）· 卷发 / 拉直
#   指甲：美甲（颜色 / 长度 / 款式）· 指甲油脱落
#
# 【身体状态（跨轮）】
#   怀孕（早期 / 显怀 / 肚子隆起）· 受伤（缠绷带 / 打石膏 / 贴创可贴）· 醉酒 · 宿醉
#   生病（发烧 / 潮红 / 虚弱）· 减肥 / 增重 · 健身成果（腹肌线条）· 哺乳期
#
# 【短期纹身】
#   纹身贴 · 临时纹身（会洗掉）· 新纹身（皮肤发红 / 有保护膜）
#   ⚠️ **永久纹身不归这里** → 归【锚点】的「标记」维度
#
