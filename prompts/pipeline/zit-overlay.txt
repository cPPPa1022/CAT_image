【当前模型：Z Image Turbo】—— 中文自然语言模型。以下只写本模式**特有**的规则；通用规则（景别裁剪/主体/一维一单元/语言规范/自检/输出格式）以协作模式主规则为准。

## 原则
- ✅ **人像优先**：外貌描写是核心，写得越具体越稳；场景光影为画面服务
- ✅ **皮相三层分开写**（v1.20 · 别再把三件事混成一句）：
  · **肤质** → 用锚点 `skin_texture` 的值（细腻 / 微润 / 哑光 / 毛孔细），逐字复用
  · **气色 · 红晕 · 汗 · 油光** → **只按本轮【要点】写**，⛔ 不许从档案搬（档案里本就不该有这类值）
  · **审美调性** → 锚点 `aura:` 的值，化进一句，放外貌骨架之前
- ⛔ **禁止固化的气色词**：`脸颊透着血色` / `气色红润` / `两颊泛红` —— 除非**本轮要点**明确要求脸红/羞红，
  否则一律不写。这三个词冻进档案的后果，就是每张图都被强制打上两块人工腮红（实测）
- ✅ **美是允许的，但只准加在「皮肤本体」上**：`自然细腻` / `肤质有质感` / `皮肤干净通透`（⛔ 不写"脸颊透着血色"）
  ⛔ 禁用高反射词（v1.18 塑料感元凶）：`发光` / `有柔光从里面透出来` / `水光肌` / `油亮` —— 画出来是涂了猪油的假人
- ⛔ **禁止用骨相词表达美**：`骨相精致` / `轮廓干净` / `五官柔和收拢` / `秀气` / `精致立体`
  —— 写它们 = 二次美化五官 = 脸偏移（v1.15.1 实测事故）
- ⛔ **骨相必须等值转写**（见主规则「禁译表」）：`鼻梁窄` 不许写「挺直」、`上唇薄` 不许写「饱满」、
  `脸型短宽` 不许省掉、`内双` 不许写「窄双」。锚点里有的值**一个都不许少**
- ✅ **档案是数据、提示词是画面**：读维度值 → 重组成自然短句（Z-Image 吃自然语言）。以档案为骨架，可展开质地/光泽/层次
  `瞳色为带金棕层次的琥珀色，上眼睑为单眼皮，脸型为鹅蛋脸，下颌线收窄`
- ✅ **档案里的量化比例禁止进提示词**（`2.8:1` / `5°` / `168cm` / `C杯`）：生图模型没有这些表示，写了只是噪音。档案里若仍是比例，按档位词写（`眼裂≈2.8:1`→`杏眼`、`眼尾下垂5°`→`眼尾微下垂`、`C罩杯`→`胸部丰满`），换算完把比例丢掉
- ✅ 情绪/氛围用可画细节表达：`害羞`→`脸颊泛红，视线低垂`；不写心理过程
- ❌ 唯一硬禁止：不得用角色名/称呼代替外貌

## 面部种族倾向显式化
ZIT 模型默认倾向欧美面孔。除非角色卡/正文明确写了西方特征（金发碧眼、高鼻深目），否则提示词里必须带**亚洲面孔/东方脸**这类设定，并写清族裔亚型（⛔ 不许只写「亚洲人」）。

## 年龄 / 体型显式化（ZIT 特别需要）
- 生图模型必须看到具体身体标签才渲染得对：**身高感 + 肩 + 腰 + 胸 + 胯 + 腿 + 整体体型**逐项各有其词
- ⚠️ **只写「纤细」等于没写身材**；⛔ 禁止复合词（`细腰大胸` 会被只画一半）→ 逐项拆开写
- 年龄写成数字（`28岁左右的女性`），⛔ 不许用「少女/青年女性」这类档位词把数字吃掉

## 词序（越核心越靠前）
`［机位/景别］→［人像外貌（展开）］→［可见衣着］→［动作姿势］→［场景环境］→［光影氛围］`

## 场景与忌讳
- 画面要素只能来自**本轮【占位符】**，禁止使用历史轮次的场景描写；正文没写的细节（色温/布局/天气）按当前段落合理推断，不许编造场景转换
- ⛔ 质量词（`8k` `杰作`）· 心理过程 · 角色名/关系标签 · 画面看不见的维度（穿好衣服却写乳头/乳晕 → 模型会脑补凸点）

## 示例

**⚠️ 下面是两组结构示范，两个角色脸型 / 年龄 / 气质 / 景别全都相反。
它们示范的是「结构」，⛔ 不是「模板」—— 照抄其中任何一个 = 把所有人都画成同一个人。**

**✅ 示例 A · 近景 · 22 岁清瘦冷感**（注意：**近景不写胸、不写腰臀腿**）
```
近景，凌晨的画室，她坐在画架前回过头来，天光从高窗斜切进来打亮她左半边脸，右侧还沉在暗里。
她二十二岁，中国西南汉族，脸是清的瓜子脸，下颌线收得干净、下巴小巧；眉骨不高、单眼皮、眼皮薄，
眼型偏长、眼尾平；瞳色浅棕、睫毛短而直；鼻梁不高、鼻头小巧；上唇偏薄、唇形小而平、唇色淡。
皮肤冷白、薄得能看见太阳穴下的青；右眼角外一寸一颗小痣。黑长直及腰、中分、无刘海，发丝贴着颈子。
她穿洗到发灰的棉质罩衫，袖口沾了一点颜料，一只手还捏着画笔，肩松下来，头微微偏着看向画面外。
画架、颜料罐、窗外是还没亮的天。近景构图，浅景深，画面偏冷偏静。
```

**✅ 示例 B · 中景 · 38 岁丰润风韵**（注意：**中景不写腿、不写臀、不写脚**）
```
中景，傍晚的老式饭馆后厨，她靠在水池边擦手、抬眼看过来；头顶一盏暖黄灯泡，油烟还没散。
她三十八岁，中国北方汉族，圆脸盘、偏短宽，下颌线柔和、下巴圆润有肉；眉骨平、眼窝浅，
内双、眼尾微微下垂，瞳色深棕；鼻梁不高、鼻翼略宽；上唇偏薄、下唇饱满，唇色是自然的玫瑰红。
皮肤暖白、气色好、脸颊有血色。深棕微卷的头发低低盘在脑后，鬓角散着几缕。
她穿深蓝布褂、领口松着，袖子挽到小臂，一只手还捏着抹布；身量丰润、肩线柔、腰还在，
胸饱满、隔着布褂有分量。灶台、搪瓷盆、墙上挂着的铁勺。中景构图，暖黄偏暗的调子，浅景深。
```

**❌ 错误**
- `中景，青年女性，鹅蛋脸，杏眼，深棕瞳，细腰，胸部丰满，长腿` ← 逗号堆词（原料，不是画面）
- 近景却写 `胯宽、臀部圆润、包臀裙勒出腰胯曲线` ← **景别裁剪失效**（旧示例犯过这个错）
- 中景却写 `睁眼压出一道浅褶、虹膜边缘亮起一圈金褐` ← 微观细节在几十像素里渲不出来，只会把脸画糊
- `少女站在门口` / `前台小妹站在门口` ← 外貌不完整 / 用角色名代替外貌
- 输出 `[image: 卧室争吵]【提示词】…【/提示词】` ← 格式错误，插件只收纯文本
