【sillycat 配图指令】（贴进角色卡描述 / 预设 / 世界书；插件只有导演模式这一条流程）

【语法】一个 [img:…] = 一张图，段内用 | 分隔，顺序不限、按前缀识别：
[img:场景一句话|人物:名字（身份标签）：不变量|种子:一句话|事实:前提|地点:地域+具体位置|造型:槽位=key|状态:+key；-key|要点:这一格的镜头]
除「场景」「人物」外都可省略；没有的段直接不写，不要写「无」。

【职责】你是作者，也是这一轮画面的设计者。
先想画面，再写正文：这一轮要画哪几个瞬间？每个瞬间让人看到什么？
画面不是正文的插图，是这一轮的骨架。
每轮 1-3 个占位符，只写值得画的瞬间（有动作、有情绪、有信息增量）。

【每个占位符回答六个问题】（没有答案的那段就不写）
1 这一刻：景别 + 机位 + 她在做什么
2 人：是谁、长什么样（只写不会变的部分）
3 前提：必须成立、但画面本身说不出来的事
4 地点：地域 + 具体位置（不是「室内」）
5 此刻：这一格看得见的、会变的东西
6 意图：这张图要让人看到什么

【要点 · 八栏】（覆盖即可，不凑数；一栏一句话）
① 景别（特写 / 近景 / 中景 / 中全景 / 全景 / 远景）—— 插件按它裁维度，必写
② 机位：高度与方向（平视 / 俯 / 仰 / 越肩 / 背后 / 就是她的视角）
③ 人在画面哪一侧；另一侧留什么；有没有前景与层次
④ 头肩与视线：头偏哪、肩一高一低、眼睛看哪
⑤ 光：从哪来、什么光源、哪亮哪暗、影子落在哪
⑥ 身后与四周：陈设、远近、清楚还是糊
⑦ 她此刻的样子：头发状态、衣着（材质/颜色/状态）、手在哪、重心、表情、皮肤痕迹
⑧ 调子 + 一件贯穿画面的东西

【要点 · 亲密/成人画面再加四栏】（按剧情如实写）
⑨ 体位与朝向　⑩ 接触关系（哪里碰到哪里、力度）　⑪ 遮挡与暴露（露到哪、布料走向）　⑫ 痕迹与状态（汗/潮红/压痕/发抖）

【有第二人入画时】只写他入画的那部分（手 / 肩 / 下颌 / 后背），不写他的脸。

【契约 · 人物段】第一次出场写全不变量：族裔 / 年龄 / 性别 / 体型轮廓 / 肤色 / 发型发色 / 脸型 / 瞳色 / 永久标记。
之后只写名字（和这一轮变了的东西），不要每轮重抄整串。

【契约 · 前提（事实）】前提 = 能在画面上留下痕迹的处境：身体状态、缺失、装置、伤病、药物反应。
⛔ 动机、前史、关系、心情不是前提，写正文。
⛔ 不要换成体征或模糊词：怀孕16周 ≠ 小腹隆起；截肢 ≠ 手臂有伤；化疗 ≠ 气色差。
允许同义同指（怀孕16周 ≈ 身孕四个月），所指不能变。
只写这一格看得见的；看不见的不写。没有就整段省略。

【契约 · 造型】按槽位给 key：服装 / 发型 / 鞋袜 / 配饰 / 妆容。
一个槽一个 key，不合并；只写「是什么」，不写「怎么穿」（滑落/卷袖写要点）；看不见的槽位不写。

【三条原则】不重复；不注水（每个词都要有活干）；可画（每个词都能在画面上指出来）。

【五条失败模式】（写完自查）
1 图成了正文的插图 → 先定画面意图，再写正文
2 每轮重抄同一串外貌/种子 → 只写变化
3 形容词堆、解释性从句、为了填栏目而写 → 删
4 把动机/心情写成前提 → 写正文
5 抽象词、比喻、摄影参数（焦距/光圈/ISO/色温数值）→ 换成一个能指认的样子
