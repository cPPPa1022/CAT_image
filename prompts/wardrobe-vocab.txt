# 造型库词表（Wardrobe Vocab）
#
# 用途：把主模型写的「造型 key」具象化成**可直接进提示词**的详情（detail），并存档复用。
# 为什么需要：服装/发型目前写在【要点】里，是自由文本，辅助AI 每轮都可能换一种说法 →
#             同一件衣服画出两个样（漂移）。存档后每轮原样复用即可消除漂移。
#
# ── 三条核心原则 ──
#   1. 【原子化】detail 必须拆成独立可命中的原子词，禁止复合词
#        ✅ white cotton t-shirt, short sleeves, round neck    ❌ casual white top
#   2. 【只存"是什么"，不存"怎么穿"】
#        detail 只描述服装本身；「滑落至肘／卷起袖／湿透／扣子敞开」属于**本轮的要点**，不进存档
#        否则「滑落」会被冻死，下一轮想穿上都穿不回来
#   3. 【key 由主模型写，插件原样使用】插件不做作用域判断（它不知道那是全校的还是个人的）

---
# 一、key 命名规范（写进主模型指令，协作卡会列出已有 key 供照抄）

| 槽 | 格式 | 例子 |
|---|---|---|
| 服装（共享） | 域·套装名 | `XX中学·校服（夏季）` `帝国军·尉官制服` `和服（正式）` |
| 服装（个人） | 人名·套装名 | `温若兰·真丝吊带+开衫` |
| 发型 | 人名·发型名 | `温若兰·短发扎尾` |
| 鞋袜 | 人名·名 | `温若兰·黑色连裤袜` |
| 配饰 | 人名·名（多个用 `、` 分隔） | `温若兰·金色细耳坠、温若兰·细项链` |
| 妆容 | 人名·名 | `温若兰·淡妆` `林晓·无妆` |

**共享 vs 个人的判断只由主模型做**：
- 同一所学校的两人穿同一套 → 写 `XX中学·校服（夏季）` → 两人命中同一条
- 个人私服/发型 → 写 `人名·…` → 千人千面，各存各的

---
# 二、服装（槽：服装）—— 一整套整体存，不要拆

⚠️ **一套校服 = 上装 + 下装 + 鞋袜 + 配饰，存成一条**。
拆开存会出现「上身夏季校服、下身冬季校服」的错配。

| 维度 | 原子词 |
|---|---|
| 品类·上 | 衬衫 / T恤 / 针织衫 / 毛衣 / 卫衣 / 吊带 / 背心 / 抹胸 / 内衣 / 睡衣 / 泳装 |
| 品类·下 | 半身裙 / 百褶裙 / 铅笔裙 / 牛仔裤 / 短裤 / 阔腿裤 / 直筒裤 |
| 品类·外 | 开衫 / 西装 / 风衣 / 大衣 / 马甲 / 制服 / 校服 / 和服 / 旗袍 |
| 品类·连 | 连衣裙 / 睡裙 / 吊带裙 |
| 领型 | V领 / 圆领 / 高领 / 立领 / 翻领 / 方领 / 一字肩 / 露肩 / 挂脖 / 深V |
| 袖型 | 无袖 / 短袖 / 七分袖 / 长袖 / 泡泡袖 / 喇叭袖 |
| 版型 | 收腰 / 宽松 / 紧身 / 短款 / 长款 / 高腰 / 低腰 / A字 / 包臀 / 直筒 / 阔腿 / 百褶 |
| 材质 | 棉 / 麻 / 真丝 / 缎面 / 雪纺 / 蕾丝 / 针织 / 羊毛 / 羊绒 / 牛仔 / 皮革 / 网纱 / 天鹅绒 |
| 颜色 | 具体色名（避免"深色/浅色"这类含糊词） |
| 花纹 | 纯色 / 条纹 / 格纹 / 碎花 / 波点 / 印花 |
| 质感 | 哑光 / 光泽 / 挺括 / 垂坠 / 半透 |

# 三、发型（槽：发型）

⚠️ **千人千面**：同一个「短发」在不同人头上不一样 → key 必须带人名。

| 维度 | 原子词 |
|---|---|
| 长度 | 超短 / 短发 / 齐耳 / 齐肩 / 中长 / 长发 / 及腰 |
| 质感 | 直 / 微卷 / 大波浪 / 蓬松 / 贴头皮 / 柔顺 / 毛躁 |
| 扎法 | 散发 / 马尾 / 高马尾 / 低马尾 / 双马尾 / 单麻花 / 双麻花 / 丸子头 / 低盘发 / 高盘发 / 半扎 / 扎尾 |
| 刘海 | 无刘海 / 齐刘海 / 斜刘海 / 空气刘海 / 碎刘海 / 中分 / 侧分 |
| 发色 | 具体色名（黑 / 深棕 / 栗色 / 亚麻…），可带渐变 |
| 发饰 | 发带 / 发夹 / 发箍 / 丝带 / 簪（也可归到【配饰】槽） |

> 发饰属于**可换的配饰**，建议单独写进【配饰】槽，不要混进发型 detail。

# 四、鞋袜（槽：鞋袜）

| 维度 | 原子词 |
|---|---|
| 袜 | 短袜 / 长筒袜 / 过膝袜 / 连裤袜 / 丝袜 / 网袜 / 无 |
| 鞋 | 高跟鞋 / 平底鞋 / 帆布鞋 / 运动鞋 / 短靴 / 长靴 / 拖鞋 / 凉鞋 / 赤足 |
| 细节 | 鞋跟高度（细跟/粗跟/平跟）、材质（皮质/帆布/绒面）、颜色 |

> 如果鞋袜是某个套装的一部分（校服配套的学生鞋），**已经包含在服装那一套里，不必单独存**。

| 颈 | 项链 / 颈链 / 锁骨链 / 丝巾 / 无 |

# 六、妆容（槽：妆容）

| 维度 | 原子词 |
|---|---|
| 底妆 | 无妆 / 素颜感 / 淡妆 / 浓妆 |
| 眼 | 眼线 / 眼影（色系）/ 假睫毛 / 无 |
| 唇 | 唇彩色（浅粉/豆沙/正红/浆果）/ 唇釉 / 无 |
| 颊 | 腮红 / 无 |
| 状态 | 晕妆 / 花妆 / 哭过的痕迹（注意：这类偏"本轮状态"，可只写要点） |

# 七、detail 详细度标准

| 槽 | detail 必须包含 |
|---|---|
| 服装 | **品类 + 款式 + 材质 + 颜色**（+ 花纹/质感） |
| 发型 | **长度 + 扎法 + 刘海 + 发色 + 质感** |
| 鞋袜 | **品类 + 款式 + 材质 + 颜色** |
| 配饰 | **部位 + 品类 + 材质 + 颜色** |
| 妆容 | **底妆档位 + 具体部位** |

**写法示例**（英文模式）：
    服装  XX中学·校服（夏季）
          white short-sleeve sailor blouse, navy collar with double white stripes,
          red neckerchief knotted at the chest, navy pleated skirt above the knee,
          cotton blend, crisp matte texture
    发型  温若兰·短发扎尾
          black chin-length hair pulled into a small low ponytail,
          wispy strands at the temples, straight, soft sheen
    鞋袜  温若兰·黑色连裤袜
          sheer black pantyhose, 20 denier, matte finish

# 八、禁止写进 detail 的内容

- ❌ 「怎么穿」：滑落 / 褪到肘 / 卷起袖 / 没扣 / 敞开 / 湿透 / 贴肤 / 扯开 → **写要点**
- ❌ 复合词：`casual outfit` / `school look` → 必须拆成原子词
- ❌ 角色名 / 人名
- ❌ 场景 / 光线 / 构图（那是要点的事）
- ❌ 剧情状态：受伤 / 淤青 / 汗 / 红晕（本轮专属）
- ❌ 数值记法：`20cm` / `3:1`（生图模型读不懂，见 atomic-vocab.txt）

---
# 九、自检
1. detail 里有没有"怎么穿"的词？→ 有就删（那是要点）
2. 每个词是不是独立可命中的原子？→ 有复合词就拆
3. 同一个 key 每次输出的 detail 是否**逐字一致**？→ 不一致就会漂
4. 服装是否含 品类+款式+材质+颜色 四项？
5. 有没有写角色名、数值、场景？
