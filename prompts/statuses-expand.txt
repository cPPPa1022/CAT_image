# 状态具象化规则（Statuses Expand）v1.9.0
#
# 触发时机：主模型在【状态】段写了 `+key`，而库里**没有**这个 key
# 你要做的：把它具象化成一条可直接进提示词的 detail，并通过 ---STATUSES--- 回传
#
# ══ 输出格式 ══
#   ---STATUSES---
#   {"左颈吻痕":"左颈，暗红色，椭圆形，吻痕","晒黑":"小麦色，全身均匀，晒黑"}
#   ---END---
#   · key 必须与输入**一字不差**（改一个字就命中不了，会重复建档）
#   · 没有未命中项 → **整段省略**
#
# ══ 规则 ══
# 1. 【只写"是什么"】不写"淡了 / 更明显了 / 快消了" —— 那是本轮【要点】的事
# 2. 【原子化】逗号分隔的独立原子，禁止长句
#      ✅ 左颈，暗红色，椭圆形，吻痕        ❌ 脖子上有个很明显的吻痕
# 3. 【位置必须具体】左/右 + 部位（左颈、锁骨下、大腿内侧…）
# 4. 【按模式语言】zit 用中文；anime / anime_tag / anima 用 Danbooru 标签
# 5. 【拿不准就不写】宁少勿编 —— 编错的信息会被**永久冻结**在库里
# 6. 【可见性】若当前画面看不到（被衣服挡住 / 中景拍不到），**仍然要具象化并回传**
#      （库里必须有），但**不要写进提示词**
#
# ══ 示例 ══
#   输入 key：左颈吻痕        ✅ {"左颈吻痕":"左颈，暗红色，椭圆形，吻痕"}
#   输入 key：晒黑            ✅ {"晒黑":"小麦色，全身均匀，晒黑"}
#   输入 key：缠绷带          ✅ {"缠绷带":"左小臂，白色绷带，缠绕"}
#   输入 key：染成奶茶棕      ✅ {"染成奶茶棕":"奶茶棕色，中长发，发尾渐深"}
