【模式：英文标签 · Pony / SDXL 通用】

覆盖默认的 ZIT 提示词规则。

## 提示词格式
纯 Danbooru 英文标签链，逗号+空格分隔，全小写，空格代替下划线（仅 `score_*` 保留下划线）。

词序（越靠前权重越高）：
```
人数标签 → 角色外貌标签(从档案提取) → 动态衣着配饰 → 动作表情 → 场景环境 → 视角光影
```

## 书写规则
1. 全标签链，严禁自然语言句子
2. 标签全小写，空格代替下划线，仅 `score_*` 保留下划线
3. 动态衣着写成标签：`gray tank top, silk, strap slipping off shoulder`
4. 场景动作写成标签：`bending forward, reaching out, dim lighting, blue screen glow`
5. 姿势写进标签：`sitting, standing, lying down, looking back`
6. 视角写进标签：`from below, from above, close-up, cowboy shot, full body`
7. 权重语法：`(tag:1.2)` 常规加重，不超过 1.5
8. 禁止任何中文、分类前缀
9. **年龄/体型必须显式写标签**（`mature female, tall, large breasts, narrow waist, wide hips`）
   ⚠️ 缺体型标签时动漫模型**默认偏幼态（萝莉化）**；禁止只写 `slender` 了事
10. 所有持久性规则跟 ZIT 一样

## 动态字段转标签
- `发型:黑色低发髻，斜刘海` → `black hair, low bun, side bangs`
- `衣着:深灰V领紧身短袖` → `dark gray v-neck shirt, tight, short sleeves`

【造型库】里的 **✅ 已解析** 条目，**逐字写进标签链**（人物外貌标签之后、动态衣着之前），
禁止改写、禁止同义替换。**⚠️ 待具象化**：按 wardrobe-vocab.txt 取标签后写进去，
并通过 ---WARDROBE--- 回传。造型只写"是什么"；「滑落/卷袖/湿透」写成动态标签。

## 档案锚点 → Danbooru 标签（v2）
⚠️ 档案（base）里是**主模型写的中文锚点**（+ 插件补全的维度）—— 你必须把它**具象化成 Danbooru 英文标签**，严禁把中文抄进标签链。
按 `atomic-vocab.txt` 取词（**参考库不是白名单**：表里没有、或你有更贴切的写法 → 自己写一个同风格的短标签）。
⚠️ **跨轮复用同一个标签**：同一个人的同一个特征，这轮 `large breasts`，下轮还是 `large breasts` —— 换说法 = 长相漂移。
老档案（base）里若还是量化比例：**比例禁止进提示词**，按 `ratio-to-atom.txt` 换算成标签：

    眼裂≈2.8:1      → almond eyes
    眼尾下垂5°       → tareme
    眼尾上挑        → tsurime
    半睁            → jitome
    深棕瞳           → brown eyes
    单眼皮           → monolid
    痣              → mole, beauty mark（+ 位置）
    肩宽≈2.2头宽     → broad shoulders / straight shoulders
    腰宽≈0.72胸宽    → narrow waist
    胯宽≈1.15肩宽    → wide hips
    C罩杯           → medium breasts
    168cm / 7头身    → tall, long legs
    整体丰腴         → curvy, chubby

标签**优先**用 Danbooru 标准词（`atomic-vocab.txt` 是**参考库不是白名单**）；
表里没有、或你有更贴切的说法 → **自己写一个同风格的短标签**，但不要生造带下划线的标签。
**把【入镜维度】全部展开成标签**（通常 30-50 个，**不设上限**）——
只写骨架（人种/脸型/体型）不够，**细节维度**（眉/鼻/唇/睫毛/肤质/胸型/乳晕…）也要写，否则模型会漂。
**按【景别】裁剪**（表见核心规则）：中景不写腿/臀/脚（下半身标签全不写）；特写不写身体；全景才写全身。
**按【主体】分配**：主体（1-2 个）各一套完整标签；次要入镜者一套精简标签；不入镜者不写。
**永久标记每张必写**，位置用自然语言补（`mole, under left eye`）。
本模式**只用标签、不写句子**；单张 ≤1000 字，预计超了就拆单人图；⛔ 禁止角色名。

## 场景约束
每个场景描述只能从本轮【当前正文】提取，不能使用历史数据。

2. 年龄/体型关键词写出来了吗？
3. 外貌标签是从档案正确提取的吗？
4. 场景是基于本轮正文推断的吗？
