# 🐱 CATimage v1.1 — 小猫的生图插件

**SillyTavern 1.18+ 第三方扩展 · 文生图人物一致性方案**

先把角色长相存进「人物档案」，之后每次出图都按档案引用——**角色不换脸**，衣着、发型、表情、场景跟着剧情走。

## v1.1 更新亮点

| 能力 | 说明 |
|---|---|
| 🎬 导演模式两轮信息交换 | 主模型（编剧+导演）在正文写 `[img:场景|人物:名字（标签），外貌|要点]` 占位符；插件 AI 只做「编辑」（按档案+要点写提示词），**不再读正文** → 最省 token 且画面贴合分镜 |
| 🗂 人物档案分层 | 脸部/身形 = 扫描锚点（权威，只读）；衣着/发型/表情 = 酒馆 AI 写的可变维度（每轮更新） |
| 🏷 身份标签 + 同名区分 | 柳如烟（千金小姐）≠ 柳如烟（青楼妓女），各存各条；裸名 ↔ 带标签自动合并（同人识别）；多同名无标签 → 跳过并警告 |
| 🔀 多人拆段 | `人物:柳如烟，赵云飞` 按已知名字集合拆分，各自继承外貌，不串味 |
| 🧊 图块精确缓存 | 按 `消息ID#块序号` 精确记录；刷新/重启后历史图逐块恢复；缓存不再每次清空 |
| ✍️ 格式硬约束 | `---PROFILE---` / `---IMAGES---` 两段式 + `---END---`，漏段 = 整轮作废；辅助调用温度 0.25 |
| 💡 动态要素保真 | 占位符内衣着/发型/表情/光线/氛围逐项列出；提示词缺失片段自动补入；场景要点 4 字覆盖检查 |
| 📐 UI | 图块尺寸档位（100/75/55/40%）、短标题（首句 ≤14 字）、显示提示词开关、手机端（<640px）猫咪条顶右 |

完整清单见 [CHANGELOG.md](CHANGELOG.md)；手把手教程见 [GUIDE.md](GUIDE.md)（新手指引）。

## 支持的模型（按提示词语言三档）

| 档位 | 提示词 | 生图模型 | 状态 |
|---|---|---|---|
| ZIT | 中文 | Z-Image Turbo | 优先适配、主要优化 |
| Anime | 英文自然语言 | Anima Base | 与 ZIT 同级适配 |
| Anime Tag | 英文标签链 | SDXL 等 tag 系模型 | 理论可用 |

## 双模式怎么选

| | 🎨 画师模式（默认） | 🎬 导演模式 |
|---|---|---|
| 谁选画面 | 专属 AI：扫卡建档 → 精读原文 → 写提示词 | 主模型：正文标 `[img:]` 位置 + 画面要点 |
| 一致性 | 最强（档案持久引用） | 好（人物表 + 标记） |
| Token | 常规（每轮多一次辅助调用） | 最省（辅助只补提示词，不读全文） |
| 配置 | 零配置（需贴「画师模式世界书」，见下） | 需在角色卡贴「导演模式世界书」 |

> 两种世界书都在 `prompts/` 目录：`artist-worldbook.txt`（画师模式：正文###…结尾### 格式约定）、`main-llm-instruction.txt`（导演模式：占位符语法 + 画师职责 + 命名规范）。插件面板也有「复制小猫指令」按钮，一键复制导演模式指令。

## 环境要求

- SillyTavern 1.18（1.17+，推荐 1.18）
- ComfyUI（本地/远程，aki 整合包可用），工作流需含 `%prompt%` 占位符
- Chat Completions API（推荐 DeepSeek）

## 安装

1. 解压到 `data/default-user/extensions/`（任意文件夹名，推荐 `sillyCAT`）
2. 刷新酒馆，右下角出现猫咪状态条
3. 面板 → 「AI 助理」：填 Chat Completions 端点/Key → 测试连接
4. 面板 → 「ComfyUI & 工作流」：填地址 → 导入工作流（含 `%prompt%`）
5. 贴对应模式的世界书（见上）→ 点「扫描角色卡」建档 → 开聊

## 设置项一览

| 分组 | 设置 | 说明 |
|---|---|---|
| 模式 | 配图方式 | 画师模式（默认）/ 导演模式，主页一键切 |
| AI 助理 | 辅助 API | 写提示词/分析档案用的模型（独立于主模型，推荐 DeepSeek） |
| 生图 | ComfyUI 地址 / 工作流 / 画风 / 负面词 | 工作流必须含 `%prompt%` |
| 生图 | NSFW 开关 | 只在 ComfyUI 侧启用 checkpoint，插件不参与审核 |
| 偏好 | 提示词风格 / 配图频率 / 额外词条 | 影响每轮提示词气质与插图像数 |
| 导演 | 导演扫描档案开关 | 导演模式是否用扫描档案补外貌（关 = 全信占位符） |
| 显示 | 图块尺寸档位 | 100 / 75 / 55 / 40%，默认 55% |
| 显示 | 显示提示词开关 | 图块顶部是否露出提示词（默认关） |
| 剧情库 | 历史轮数 | 历史正文重放轮数（画师模式，默认 5） |

## 人物档案机制（一图流）

1. **扫描**：读角色卡 → 脸部（脸型/眉眼/鼻唇/肤色）+ 身形（体型/发型…）→ 写入 `base`（权威，不再变）
2. **每轮**：酒馆 AI 在正文/占位符写的**可变维度**（衣着/发型/表情/光线/氛围）→ 记入 `live`，覆盖只对这一轮生效
3. ***更新***：酒馆 AI 更新外貌时回执 → 插件并入档案
4. **新人物**：正文/占位符报一次外貌即自动建档（NPC、世界观路人同样处理）

核心规则：**档案管「长相」，酒馆 AI 管「穿戴」**。人物段只写名字（同名不同人行带标签），格式必须严格。

## 常见问题

- **人物不一致？** 确认扫描过角色卡（画师模式）；新人物在正文/占位符报一次外貌；同名人物带身份标签
- **提示词像中文剧情文字？** 检查辅助模型是否遵守 `prompts/roster/system.txt`（禁止照抄场景）；格式硬约束会整轮作废不合格输出
- **刷新后历史图片不显示？** v1.1 已修复：加载后 12s 就绪探测 + DOM 观察器，按 `消息ID#块序号` 精确恢复
- **缓存总是一次聊天就丢？** v1.1 已修复：不再每次页面加载清空；仅首次升级时清理一次旧缓存
- **画师模式没图？** 检查角色卡是否贴了 `artist-worldbook.txt`（正文###/结尾### 标记是画师模式的输入）
