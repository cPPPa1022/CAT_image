# 【这是什么】—— 先读这一节，它决定你怎么用整份文件

#   ⚠️ 这是**坐标轴标定表**，不是"选择题菜单"。
#      · 每个维度后面的词 = 这条轴的**端点**，用来让你定位"往哪边偏"
#      · ⛔ **禁止直接把表里的值照抄进锚点**（照抄 = 填词游戏 = 所有角色长同一张脸）
#        —— 2026-10-17 实测 591 张图：asian 出现 206 次；oval face 占 65%；
#           flat brow bone 占 79%；narrow double eyelids 占 81%；aegyo-sal 占 77%
#           —— 全是"照抄本表最顺手那一档"的结果
#      · ✅ 正确用法：用端点确定方向，然后**自己写值**，写到"能跟同聊天另一个人一眼分开"的精度
#        例：眼睑轴 = 单眼皮 ←→ 深双眼皮
#            照抄（❌）：narrow double eyelids
#            自己写（✅）：极浅的内双，睁眼时只剩一道压痕，眼皮偏厚略肿
#   ⚠️ 最终产物是**写成画面的句子**，不是把词用逗号堆起来。
#      ❌ 杏眼，内双，深棕瞳，长睫毛
#      ✅ 她的眼睛是标准的杏眼，眼型偏长、眼尾微微下垂；上眼睑是内双，睁眼时压出一道浅浅的褶
#   ⚠️ 写之前先按【景别】裁剪（裁剪表在 roster/system.txt）：中景不写腿/臀/脚，特写不写身体
#   ⚠️ 主体（1-2 个）逐维展开成句；次要入镜者维度不省但写短；不入镜者不写
#
# 【三条使用规则】
#   1. **同一角色跨轮**：同一特征必须复用同一个词（包括你自创的）—— 换说法 = 漂移
#   2. **同一维度跨角色**：必须换档 —— 这一档被同聊天其他角色占了，就换到轴的另一段
#   3. **允许自创**：表里没有、或你有更贴切的写法 → 自己造一个同风格的短词；**造完就冻结**
#   单一特征一个词，禁止复合词：细腰，大胸，长腿 ✅ / 细腰大胸 ❌
#
# 【两个阶段，规则完全不同 —— 这是最容易搞混的地方】
#
#   ① 建档阶段（写进角色档案 base）：**写全**
#      档案描述的是"一个完整的人"，每个维度都要有值，或明确不适用。
#      建档不设原子数量上限 —— 它是全集，不是某一张图。
#
#   ② 写提示词阶段（每张图）：**做减法**
#      画面里看不见的维度不写。
#      例：角色穿着衣服/内衣且没有凸显 → 不写乳头、乳晕、乳沟。
#          （硬写会让模型自己脑补，画成"穿得好好的却莫名凸点"）
#      例：全身远景 → 不写卧蚕、泪痣、唇形这些特写才看得见的。
#
# 【铁律】
#   1. 禁止数值/比例/角度/cm/罩杯字母进提示词（2.8:1 / 5° / 168cm / C杯）
#      —— 比例只是"选择器"，选完即丢
#   2. **不做性别预判**：身体部位只取这个角色**实际存在**的部位。
#      判断依据是角色卡 / 剧情 / 主模型的描述，
#      不是"男性该有什么、女性该有什么"的任何预设。
#      拿不准的维度 → 宁可不写，也不要凭空造。
#   3. 每张图的原子总数 15-25（建档不设上限，见上）
#
# 【标记说明】
#   🟢 = 目标模型（Danbooru 系）有标准标签

# 二·五、社会身体层（L2 · v1.11 新增）—— 这一层**不进标签链**

  ⛔ 禁止把 L2 拆成一堆标签塞进标签链。

# 四、词序（越靠前权重越高 · v1.11 修订）

  族裔亚型 → 脸骨架（脸型/下颌/颧骨/下巴/眉骨）→ 眼（型/眼距/眼睑/眼尾/瞳色/眼球突出度/眼皮厚度/虹膜占比）
  → 鼻（根/梁/翼/头）→ 唇 → 肤色肤质 → 发 → 颈 → 体态 → 体型（身高/肩/腰/胸/胯/腿）→ 衣着 → 姿势 → 场景

  · 反差支点加权：(toned calves:1.2) —— 不加权会被“纤细/瘦小”盖掉
  · 权重只给 2-4 个标签，范围 1.1-1.3
  · ⛔ 「美女默认词」不要写：smooth skin / long eyelashes / aegyo-sal / delicate / beautiful / starry eyes
    （除非种子或角色卡明确要求 —— 它们是“所有人长一样”的胶水）

# 五、自检（写提示词前）

  1. 提示词里还有数字/比例/角度/cm/罩杯字母吗？→ 有就删，换档位词
  2. 是"一个特征一个词"吗？→ 有复合词就拆
  3. 画面里看不见的维度写了吗？→ 写了就删（尤其乳头/乳晕/乳沟/生殖器）
  4. 这个角色的部位，是你**确认存在**的吗？→ 拿不准就删，不要凭空造
  5. 原子的总数在 15-25 之间吗？→ 超了就优先删特写细节
  6. **有没有一句“只属于这个角色”的东西**（反差支点/记忆点）？没有 = 一张可以替换任何人的脸
  7. **这些值是从本表照抄的吗**？→ 是就重写：用端点定方向，自己造值
  8. **L2（体态/痕迹/打理/皮肤状态/表情纹/成熟度）写了吗**？写了的话，是不是自然语言而不是标签？
