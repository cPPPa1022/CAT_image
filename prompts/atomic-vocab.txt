# 生图原子词表 v3.0（压缩版 · 1200 行 → 60 行）

# 【这是什么】坐标轴标定表，不是选择题菜单。
#   每组后面的词 = 这条轴的**端点**，用来定方向；⛔ 禁止照抄表里的值（照抄 = 填词 = 所有角色同一张脸）。
#   实测 591 张图照抄的后果：asian 206 次 / oval face 65% / flat brow bone 79% / narrow double eyelids 81% / aegyo-sal 77%。
#   ✅ 用法：端点定方向 → 自己写值 → 写到「能跟同聊天另一个人一眼分开」的精度。
#      例：eye 睑轴 单眼皮 ←→ 深双眼皮；照抄 `narrow double eyelids` ❌；自己写 `极浅内双，睁眼只剩一道压痕，眼皮偏厚略肿` ✅
#
# 【三条规则】
#   1. 同一角色跨轮：同一特征复用同一个词（含自创词）—— 换说法 = 漂移
#   2. 同一维度跨角色：必须换档（这一档被别人占了 → 换到轴的另一段）
#   3. 允许自创；但**造完就冻结**。单一特征一个词，禁止复合词：细腰·大胸·长腿 ✅ / 细腰大胸 ❌
#
# 【两阶段】建档 = 写全（全集，不设上限）；写提示词 = 做减法（画面看不见的不写）
# 【铁律】① 禁止数值/比例/角度/cm/罩杯字母进提示词（比例只是选择器，选完即丢）
#         ② 不做性别预判：只写角色实际存在的部位，拿不准就不写
#         ③ 最终产物是**写成画面的句子**，不是逗号堆词
