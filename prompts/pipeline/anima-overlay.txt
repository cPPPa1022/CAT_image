【模式：Anima 混合式 · Danbooru 标签 + 自然语言】

Anima 系模型由两类语料共同训练：
- **Danbooru 标签** → 擅长「结构 / 精度 / 构图」（人物长相、体型、衣着、镜头）
- **自然语言 caption** → 擅长「氛围 / 光影 / 情绪」（画面质感、光线、气氛）

**纯标签会丢氛围，纯描述会丢结构与精度。** 本模式采用三段式混合写法。

## 提示词结构（三段式，顺序固定）

    ① 结构段（Danbooru 标签） —— 人种/年龄/脸/体型/衣着/姿势，逗号+空格分隔，全小写
    ② 氛围段（自然语言一句）   —— 光影 / 氛围 / 情绪，一句英文，≤40 词
    ③ 构图段（标签）          —— 景别 / 机位 / 景深，3-5 个标签

示例（结构段要**写全**：脸的全部细节 + 体型 + 衣着，通常 30-50 个标签；**不是只写十几个**）：
    asian, 1girl, solo, young woman, mature female, oval face, soft jawline, small chin, high brow bone,
    almond eyes, downturned eyes, narrow double eyelids, long eyelashes, brown eyes, amber eyes,
    aegyo-sal, straight eyebrows, dark brown eyebrows, straight nose bridge, small nose tip,
    narrow nostrils, full lips, pale pink lips, fair skin, smooth skin, very long wavy hair, side part,
    no bangs, dark brown hair, slender neck, visible collarbone, tall, narrow shoulders, narrow waist,
    large breasts, wide hips, long legs, curvy, light blue cotton shirt, buttoned up, beige knit
    cardigan. A warm ceiling lamp spills honey-colored light over her shoulders while the hallway
    behind her stays dim, the air quiet and still. close-up, eye level, shallow depth of field

## 分工表（关键，别用错）

| 内容 | 用什么写 | 理由 |
|---|---|---|
| 人种 / 年龄 / 性别 | **标签** | `asian` `mature female` 绑定强 |
| 脸型 / 眼睛 / 眉毛 / 头发 | **标签** | 结构化、可复现 |
| 永久标记（痣/疤） | **标签** | `mole` `beauty mark` 绑定明确 |
| **体型（胸/腰/臀/腿/身高）** | **标签** | `large breasts` `narrow waist` 是最有效的体型控制手段 |
| 衣着 / 材质 / 状态 | **标签** | `silk` `lace` `sheer` `strap slipping` 视觉绑定明确 |
| 姿势 / 动作 | **标签 + 短语** | `lying on sofa` `hand covering mouth` |
| **光影 / 氛围 / 情绪** | **自然语言** | 标签覆盖不全，只有自然语言带得出质感 |
| **造型（服装/发型/鞋袜/配饰/妆容）** | **标签** | 来自【造型库】的 detail —— **已解析的逐字照抄进结构段，禁止改写** |
| 景别 / 机位 / 景深 | **标签** | `close-up` `from below` `shallow depth of field` 精度更高 |

## 书写规则
1. 结构段：全小写，空格代替下划线，逗号+空格分隔（仅 `score_*` 保留下划线）
2. 氛围段：**只写一句**，只写光影/氛围/情绪，**禁止复述结构信息**（不要在里面再写脸和衣服）
3. 构图段：3-5 个标签
4. **禁止出现中文**、禁止分类前缀（`脸型:` `衣着:`）
5. 权重语法：`(tag:1.2)`，不超过 1.5
6. **结构段要把【入镜维度】全部写成标签**（通常 30-50 个，不设上限）——
   只写骨架（人种/脸型/体型）不够，**细节维度**（眉/鼻/唇/睫毛/肤质/胸型/乳晕…）也要写，否则模型会漂
   **按景别裁剪**（表见核心规则）：中景不写腿/臀/脚；特写不写身体
   **按主体分配**：主体（1-2 个）各一套完整标签；次要入镜者一套精简标签；不入镜者不写
   单张 ≤1000 字（2 主体 800-1000 到顶），预计超了就拆单人图
7. 标签**优先**用 Danbooru 标准词（见 `atomic-vocab.txt`，那是**参考库不是白名单**）；
   表里没有、或你有更贴切的写法 → **自己写一个同风格的短标签**，但**不要生造带下划线的标签**

## ⚠️ 年龄 / 体型必须用标签显式写全（防幼态化）
Anima 系模型在缺少体型标签时**默认偏幼态（萝莉化）**。成年角色必须写全：

    mature female, tall, large breasts, narrow waist, wide hips, long legs

- 身高感：`petite` / `tall` ｜ 肩：`broad shoulders` / `narrow shoulders` / `straight shoulders`
- 腰：`narrow waist` / `slim waist` ｜ 腿：`long legs` / `thick thighs`
- 胸·大小：`flat chest` / `small breasts` / `medium breasts` / `large breasts` / `huge breasts`
- 胸·胸型：`sagging breasts` / `hanging breasts` / `teardrop breasts` / `sideboob` / `cleavage`
- 胸·乳晕 / 乳头：`large areolae` / `dark areolae` / `puffy nipples` / `inverted nipples` / `erect nipples`
- 臀 / 胯：`wide hips` / `thick thighs` / `round ass` ｜ 胸肌：`pectorals` / `muscular chest` / `visible pectorals`
- 体毛 / 生殖器：`pubic hair` / `shaved` ｜ `penis` / `pussy` / `clitoris` / `uncensored`（**只写该角色实际有的部位**，拿不准就不写）
- 年龄：`teenage girl` / `young woman` / `mature female` / `middle-aged` / `young man`
- ⚠️ **看不见就不写（只删 L3/L4）**：穿着衣服且无凸显 → 不写乳头/乳晕/乳沟；远景 → 可省睫毛/肤质等细节层
  （硬写会让模型脑补出"衣服穿得好好的却莫名凸点"）
- ⚠️ **L1 身份锚 + L2 形体锚每张必写，不受景别影响**（中景/远景也要写全，砍了就每张换脸）
- ⛔ 结构段禁止出现角色名，全部用标签替代

**禁止只写 `slender` / `slim` 这类体脂词了事** —— 那等于没写身材，模型会退回默认幼态。

## 档案锚点 → 结构段标签（v2）
⚠️ 档案（base）里是**主模型写的中文锚点**（+ 插件补全的维度）—— 你必须把它**具象化成英文标签**写进结构段，不是照抄中文。
按 `atomic-vocab.txt` 取词（**参考库不是白名单**：表里没有、或你有更贴切的写法 → 自己写一个同风格的短标签）。
**身份锚（瞳色/痣/疤痕/罕见发色）每张必写且逐字一致** —— 这是"像不像同一个人"的核心。
⚠️ **跨轮复用同一个标签**：同一个人的同一个特征，这轮 `large breasts`，下轮还是 `large breasts` —— 换说法 = 长相漂移。

老档案里若还是量化比例：**比例禁止进提示词**（生图模型没有对应表示，写了只是噪音），按 `ratio-to-atom.txt` 换算：
    眼裂≈2.8:1 → almond eyes ｜ 眼尾下垂5° → tareme ｜ 腰宽≈0.72胸宽 → narrow waist
    C罩杯 → medium breasts ｜ 168cm/7头身 → tall, long legs ｜ 眼距≈一眼宽 →（不写）

永久标记每张必写：`mole` / `beauty mark` + 位置短语（`mole, under left eye`）。

## 场景约束
每个场景描述只能从本轮【当前正文】提取，不能使用历史数据。

## 自检
1. 结构段是纯标签吗？氛围段是自然语言吗？两者有没有混在一起？
2. 体型标签（胸/腰/臀/腿）写全了吗？只写 slender 不算
3. 氛围段有没有复述结构信息？→ 有就删
4. 出现中文了吗？→ 有就删
5. 永久标记写了吗？用词和上一轮一致吗？
